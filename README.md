# Karan Divakar — SEO Portfolio

A futuristic, fully responsive SEO portfolio website.

## How to Run

### Option 1 — VS Code Live Server (Recommended)
1. Open the `karan-seo-portfolio` folder in VS Code
2. Install the **Live Server** extension (by Ritwick Dey) if you haven't already
3. Right-click `index.html` → **"Open with Live Server"**
4. Browser opens automatically at `http://127.0.0.1:5500`

### Option 2 — Direct Browser
Just double-click `index.html` — it opens directly in your browser, no server needed.

### Option 3 — VS Code Simple Browser
Open `index.html` in VS Code and press `Ctrl+Shift+P` → type **"Simple Browser"** → enter the file path.

## Features
- Futuristic dark theme with glowing cyan/green accents
- Custom animated cursor
- Floating particles background
- Scroll-triggered fade-in animations
- Interactive SEMrush analytics tabs (4 sites)
- Animated skill progress bars
- Fully mobile responsive
- No external JS dependencies — works offline
